User Story: As a registered user, I want to log in using my credentials so that I am authenticated and immediately presented with the centralized main dashboard displaying incident summaries, high-risk alerts, quick navigation, and website visit statistics.
Acceptance Criteria:
1.	Entering valid credentials successfully authenticates the user (FR2) and instantly redirects them to the main dashboard without requiring an intermediate page load.
2.	The loaded dashboard displays all required widgets—total incidents, high-risk alerts, quick navigation shortcuts, and website visit statistics—pulled dynamically from the system upon login (FR3).

User Story: As an analyst, I want to view an interactive 2D crime density heatmap separated by crime categories so that I can simultaneously analyze current spatial distributions alongside predictive crime rate forecasts generated by machine learning for specific zones.
Acceptance Criteria:
1.	The user interface displays both the interactive 2D hotspot map with category filters (FR4) and the machine learning-based crime rate prediction panel for selected zones (FR5) on the same workspace.
2.	Selecting or filtering a specific crime category on the 2D map dynamically updates the corresponding zone-based predictive metrics or highlights the correlation with historical data.

User Story: As a new system participant, I want to register an account with my name, official email, and secure password so that my credentials are securely established and I can immediately access the main dashboard overview to track system activity and site statistics.
Acceptance Criteria:
1.	Submitting the registration form with a valid official email and strong password creates the account and saves the credentials securely (FR1).
2.	Upon completing registration and first login, the user is seamlessly routed to the centralized main dashboard view featuring the summary of incidents, alerts, navigation, and website visit metrics (FR3).
