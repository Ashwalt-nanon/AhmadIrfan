Functional Requirement

FR1
User Registration
The system will allow new users to register an account providing their name, official email address, and a strong secure password

FR2
User Authentication (Login)
The system will authenticate users by verifying their email and password against stored secure credentials, granting access if it is authenticated 

FR3
Main Dashboard Overview
The system will present a centralized main dashboard after login, displaying summary of total incidents, high-risk alert, quick navigation, and statistic of website visits

FR4
2D Hotspot Visualization
The system will display an interactive 2D visualization hotspot of crime density heatmaps, that also separated in category like types of crime

FR5
Crime Rate Prediction
The system will generate and display predictive crime rate forecasts for specific zones using machine learning on historical crime data


Non-Functional Requirement

NFR1
Performance and Speed
The 2D hotspot map will load and render completely within 3 seconds under normal network conditions

NFR2
Security and Data Privacy
All users credential, personal data, and sensitive incidents logs must be encrypted in transit to comply with law enforcement data protection standard

NFR3
Availability and Reliability
The system will maintain ap uptime availability of at least 99.9% on an annual basis, ensuring that emergency and operational mapping tools remain accessible 24/7
